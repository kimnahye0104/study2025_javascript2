# 자바스크립트 기본기 총정리
## A. 변수 선언 기본 규칙
1. 변수 선언할 때는 변하지 않는 값은 `const`, 변할 수 있는 값은 `let`으로 선언하기.
2. `const는 대문자`로 작성하는 것이 좋음.
3. 변수는 '문자, 숫자, $'만 사용.
4. 첫글자에는 숫자가 올 수 없음.
5. 예약어 사용할 수 없음.
6. 상수(const)는 가급적으로 대문자.
7. 변수명은 읽기도 이해하기도 쉽게 선언.
* (TIP!) 모든 변수를 const로 선언하고 변경여지가 있는 변수만 let으로 작성하기.
## B. 자료형
1. 문자형(String)은 3가지 방식으로 작성 `큰따옴표,작은따옴표,베틱기호`
* 작은따옴표를 써야 하는 경우 앞에 `역슬러시(\)`를 넣어주면 특수문자로 인식함.
2. 숫자형
3. boolean
4. null과 undefined
5. typeof 연산자
* null은 객체가 아님. (js초기버전의 오류.)
## C. 창 띄우기
1. `alert` : 경고창, 알려줌.
2. `prompt` : 입력받음.
* 취소를 누르면 NULL.
* 디폴트 값을 입력할 수 있음.
* 입력받은 값은 무조건 문자형!!이 된다.
3. `confirm` : 확인 받음.(확인/취소)
### alert, prompt, confirm의 단점
* 스크립트 일시 정지 (동작이 제한 된다.)
* 스타일링 불가. (위치,디자인 설정 불가. 브라우저마다 디자인 다름.)
## D. 형변환(Type Conversion)
*형변환이 필요한 이유 : 다른 형을 결합하면 의도치 않은 동작 발생 = 오류 가능성 up!
*나누기,곱하기>덧셈,뺄셈>문자 순으로 먼저 계산됨.
1. String()
2. Number()
* 숫자와 문자가 같이 쓰이면 NaN이 되므로 주의!
* true = 1, false = 0.
3. Boolean()
* `false`의 케이스만 기억하기!
* `0, 빈문자열, null, undefined, NaN`은 모두 false.
### 형변환 주의할 점.
* `Number(null)`은 0
* `Number(undefined)`은 NaN
* `Number(0)`은 false, `Number('0')`은 true
* `Number('')`은 false, `Number(' ')`은 true(공백이 있으면 true.)
