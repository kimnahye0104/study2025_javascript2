# 자바스크립트 기본기 총정리
## A. 변수 선언 기본 규칙
1. 변수 선언할 때는 변하지 않는 값은 `const`, 변할 수 있는 값은 `let`으로 선언하기.
2. `const는 대문자`로 작성하는 것이 좋음.
3. 변수는 '문자, 숫자, $'만 사용.
4. 첫글자에는 숫자가 올 수 없음.
5. 예약어 사용할 수 없음.
6. 상수(const)는 가급적으로 대문자.
7. 변수명은 읽기도 이해하기도 쉽게 선언.
* (TIP!) 모든 변수를 const로 선언하고 변경여지가 있는 변수만 let으로 작성하기.
## B. 자료형
1. 문자형(String)은 3가지 방식으로 작성 `큰따옴표,작은따옴표,베틱기호`
* 작은따옴표를 써야 하는 경우 앞에 `역슬러시(\)`를 넣어주면 특수문자로 인식함.
2. 숫자형
3. boolean
4. null과 undefined
5. typeof 연산자
* null은 객체가 아님. (js초기버전의 오류.)
## C. 창 띄우기
1. `alert` : 경고창, 알려줌.
2. `prompt` : 입력받음.
* 취소를 누르면 NULL.
* 디폴트 값을 입력할 수 있음.
* 입력받은 값은 무조건 문자형!!이 된다.
3. `confirm` : 확인 받음.(확인/취소)
### alert, prompt, confirm의 단점
* 스크립트 일시 정지 (동작이 제한 된다.)
* 스타일링 불가. (위치,디자인 설정 불가. 브라우저마다 디자인 다름.)
## D. 형변환(Type Conversion)
*형변환이 필요한 이유 : 다른 형을 결합하면 의도치 않은 동작 발생 = 오류 가능성 up!
*나누기,곱하기>덧셈,뺄셈>문자 순으로 먼저 계산됨.
1. String()
2. Number()
* 숫자와 문자가 같이 쓰이면 NaN이 되므로 주의!
* true = 1, false = 0.
3. Boolean()
* `false`의 케이스만 기억하기!
* `0, 빈문자열, null, undefined, NaN`은 모두 false.
### 형변환 주의할 점.
* `Number(null)`은 0
* `Number(undefined)`은 NaN
* `Number(0)`은 false, `Number('0')`은 true
* `Number('')`은 false, `Number(' ')`은 true(공백이 있으면 true.)
## E. 연산자(Operators)
* `%` : x를 N으로 나눴을때의 나머지 값을 반환. (홀짝 구분, 반환할 수의 범위 지정 가능.)
* `**` : 거듭제곱
### 연산자 줄여쓰기.
* `+=`, `-=`, `/=`, `*=`, `%=`
### 증가 연산자, 감소 연산자
* `++`,`--`,
* (주의할점) 연산자를 작성하는 위치 중요! 변수의 앞뒤 잘 생각하기.
## F. 비교 연산자
* `<(크다)`, `>(작다)`, `<=(크거나 같다)`, `>=(작거나 같다)`, `==(같은가)`,`!=(다른가)`
* ==, != : 같은가 다른가를 비교하는 연산자가 반환하는 값은 항상 boolean(true, false)이다.
### 동등연산자 주의할 점! (일치연산자 활용법)
* `==(동등연산자)` : 형태(type) 상관 없이 비교하기에 숫자형 1과 문자형 1을 같다고 반환함.
* `===(일치연산자)` : 형태(type)까지 비교함. 숫자형 1과 문자형 1은 같지 않다고 반환함.
* 타입까지 비교해주는 일치연산자를 사용하는 것이 오류 가능성을 낮춤.
## G. 조건문(if)
* `if` : 괄호 안에 조건이 true면 실행.
* `else` : if문의 조건이 false일 때 실행. (else if 마저 false이면 실행.)
* `else if` : if문의 조건이 false일 때 실행.
## H. 논리연산자
* `||` : OR : 여러개 중 하나라도 ture이면 true. (모든 값이 false일 때, false 반환.) `true 발견 즉시 평가를 멈춤.`
* `&&` : AND : 모든 값이 true이면 true. (하나라도 false이면 false를 반환.) `false 발견 즉시 평가를 멈춤.`
* `!` : NOT : true면 false. false면 true.
### 논리연산자 주의할 점!(성능 최적화 방법)
* '운전면허가 있고 시력이 좋은 여군'을 뽑는 프로그램을 만들때,
* 여군 = 전체군인의 7%, 시력이 좋은 = 전체군인의 60%, 운전면허가 있는 = 전체군인의 80%.
* 코드 작성 예시 : `여군인데, 시력이 좋고, 운전면허가 있는 사람`
* 우선순위 (AND > OR) : AND(&&)는 OR(||)보다 먼저 평가됨.
## I. 반복문
*  `for`, `while`, `do while`
* for문 : `for( 초기값; 조건; 코드 실행 후 작업 ){ //반복할코드 }`
* while문 : `let i = 0; while(조건){ // 코드 }`
* do while문 : `let i = 0; do(){ // 코드 }while(조건건)`
### 반복문 중지
* `break` : 멈추고 빠져나옴.
* `continue` : 멈추고 다음 반복 실행.
### TIP
* 명확한 횟수가 정해져 있다 : for문
* 명확한 횟수가 정해지지 않았다 : while문
